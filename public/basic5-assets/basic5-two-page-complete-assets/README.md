## How Codex should use the pack

1. Build cards, text, buttons, counters, progress values and responsive layout in
   React/HTML/CSS. These elements must remain live and accessible.
2. Use the transparent PNGs for mascots, icons, badges, routes, ornaments and
   watermark artwork.
3. Place `dashboard/transparent-png/choose-week-route-only.png` behind the
   dashboard week cards.
4. Place `week1/transparent-png/learning-rail-only.png` behind the five Week-1
   activity cards.
5. Use the composite images to verify exact spacing, curves and proportions.
6. Preserve the supplied aspect ratios. Do not stretch any mascot or icon.
7. Keep the purple rich and warm. Do not replace it with blue.

## Coordinate reference

`implementation-map.json` contains the original canvas dimensions and exact

## Important

The files in `exact-crops/` retain the supplied screenshot pixels. The files in
`transparent-png/` are ready for direct use. The enhanced lion images were
created only to provide larger production-ready alternatives; the
`*-original.png` versions should be used for the closest screenshot match.
